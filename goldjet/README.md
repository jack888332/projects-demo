# 高捷物流一期系统高保真原型

产品事实以用户当前确认和 [Goldjet 分篇 PRD](../../projects-doc/product-caliber/goldjet/segmented-prd/PRD.高捷物流系统一期.第001篇.概览与索引.369FCA625E.md) 所在主库为准；原型是浏览器内的可运行表达，不是第二份需求来源。原型实现发现的冲突及已确认待同步项记录到 [PRD 自洽性问题](../../projects-doc/product-caliber/goldjet/analysis/PRD自洽性问题.md)，不据此改写主库规则。

## 运行与数据

在本目录执行 `npm run dev`，访问 [本机原型](http://localhost:10530/)。首次安装依赖使用 `npm ci`。

- 保留 Vue 3、Vite、Vue Router、Element Plus 和现有设计令牌。
- `desktop-browser`：目标画布 1440×900、简体中文、Asia/Shanghai、精细指针和键盘；司机、空运主数据、运输报价、仓库报价、空运供应商价格、舱位、配板、子订单、补录及提单/模板页另外完成 390×844 的相应列表/编辑/弹窗冒烟，不代表其他页面或完整响应式矩阵已验证。
- 固定演示日期为 2026-09-08；名称、邮箱、车牌、身份证、航班、报价和授信均为合成数据。请勿填入真实敏感资料。
- 产品数据由 `src/data/usePrototypeData.js` 单一内存 owner 管理。跨页共享；刷新或顶部“恢复演示数据”恢复固定 seed。
- 顶部切换空运、航晟、业务、财务与主数据维护角色；切换会明确确认丢弃草稿。这不是生产认证或服务端权限。
- 不连接真实航司、WMS、司机端、地图、邮件、企业微信或财务系统。

## 待确认规则

- Minimum 的具体输入范围及其参与报价/盈利计算的口径尚不完整；不自行套入公式。
- 直航情况下二程目的地、三程航段在字段表仍为必填，目前保留该校验并提示边界待确认。
- 航程与航程补充未逐字段明确归属；目前仅作展示分组，不凭分组扩张航线操作权限。
- 亏损超过 5,000 元追加事业部副总、超过 10,000 元追加事业部总经理，按第030篇逐级审批；超过 30,000 元的触发人与发起人衔接有歧义，暂不提交。最终审核通过仅推进主订单为待补录，订舱服务仍待审核并明确提示；拒绝与重提未开放。
- 零可用授信在第003篇为禁止下单、第009篇仅禁止负数，原型阻断零值并提示先审批增加额度。档案拒绝后的主状态、客户已有银行/联系人行修改、供应商匹配后字段修改也有冲突；仅限制对应分支，额度拒绝已可执行。
- 航司提单前缀是否唯一、航班“到达时间”含义存在冲突；管理员删除航司和板型的权限未明确。航线专员新增航司已按详细场景开放。公布运价的维护与计算、引用对象删除后的迁移未明确，不自行补造。
- 订舱页航司候选来自舱位产品，运营/操作默认勾选本人绑定航司；筛选不作授权依据，详情深链不受当前查询条件限制。日期默认不限；“待订舱”插在待审核之后、同状态创建时间升序是待确认排序口径下的演示选择。
- 第010篇新增 GJ-PRD-091～094：重订后的已补录结果、最晚送货时间来源、合成计重与重算、成本单改及航晟完成的通知边界。当前保留主单与补录状态，只回退订舱服务；合成页展示保存的聚合报价和来源子单，不把期望到货时间改称送货时间，不推定未决通知。
- 第011篇新增 GJ-PRD-095～101并校准029、030。已明确的主分单暂存/提交和发送顺序均已实现；未定义的出单后修改、成功后变更有效性、总价及业务模板配置保留限制。上传文件只到“已上传”，主/分单提交均按本篇推进主订单到已出提单；不会以预计货物替代实测提单数据。
