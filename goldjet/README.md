# 高捷物流一期系统高保真原型

产品事实以用户当前确认和 [Goldjet 分篇 PRD](../../projects-doc/product-caliber/goldjet/segmented-prd/PRD.高捷物流系统一期.第001篇.概览与索引.369FCA625E.md) 所在主库为准；原型是浏览器内的可运行表达，不是第二份需求来源。原型实现发现的冲突及已确认待同步项记录到 [PRD 自洽性问题](../../projects-doc/product-caliber/goldjet/analysis/PRD自洽性问题.md)，不据此改写主库规则。

## 运行与数据

在本目录执行 `npm run dev`，访问 [本机原型](http://localhost:10530/)。首次安装依赖使用 `npm ci`。

- 保留 Vue 3、Vite、Vue Router、Element Plus 和现有设计令牌。
- `desktop-browser`：目标画布 1440×900、简体中文、Asia/Shanghai、精细指针和键盘；司机、空运主数据、运输报价、仓库报价、空运供应商价格、舱位、配板、子订单、补录、提单/模板、仓库订单、货站打板及财务基础页另外完成 390×844 的相应列表/编辑/弹窗冒烟，不代表其他页面或完整响应式矩阵已验证。
- 固定演示日期为 2026-09-08；名称、邮箱、车牌、身份证、航班、报价和授信均为合成数据。请勿填入真实敏感资料。
- 产品数据由 `src/data/usePrototypeData.js` 单一内存 owner 管理。跨页共享；刷新或顶部“恢复演示数据”恢复固定 seed。
- 默认进入超级管理员，可查看所有已接入界面和演示数据、配置角色权限；不代替业务岗位审批或改变业务状态。顶部可切换原有业务角色，切换前确认丢弃草稿。这不是生产认证或服务端权限。
- [角色权限](http://localhost:10530/#/foundation/permissions) 按角色配置模块菜单、页面访问、数据查看和业务操作，支持保存、恢复默认及变更记录。数据范围与操作资格仍受原有岗位规则限制；本轮不提供自定义角色、逐按钮授权、组织范围或字段脱敏配置。
- 权限配置由 `src/data/accessControl.js` 单一内存 owner 管理，保存后在本会话生效。刷新或顶部恢复同时清除自定义权限并回到超级管理员；默认载入现有报关、在途、运单合成样例，不覆盖用户操作结果。
- 不连接真实航司、WMS、司机端后端、地图、邮件、企业微信或财务系统；第018篇司机端是浏览器内本地模拟。

## 字段覆盖与边界

货站打板由“货站打板人员”维护，超级管理员全量只读；航线运营/操作查看本人配板计划，空运人员按显式关联查看板纸。订单承接全部13项创建字段、5项查询及9项业务列表字段，客户订单号不去重，财务组织默认广州航晟物流有限公司；上游消息未带的字段留空，不套用手工默认值。新建或接收成功仅保存已明确字段，初始状态显示待确认，不推进状态或自动计费。已有明确为“待入站”的本地样例可删除，内部上游单不可删除。关联账单只读且仅取本订单ID，货站岗位不能直达费用总表；管理员可收紧数据查看和业务操作权限。

打板报价保留10字段、常规方式、同日起止、500字备注和更新时间倒序，不照搬仓库报价的状态/启停规则。复杂算法、部分编辑继承及引用后重算未决时阻断；客户被打板订单或报价引用后不可删除。计划直接读取第008篇已配板记录，不另存货量；补充字段和正式Excel模板待确认，导出不伪造成功。已有板纸须1～9张且单张严格小于6MB，复用JPG/PNG/BMP解码和预览，这是原型格式假设；修改时锁定航班号、保留完成时间、不推进订单，并给显式合成收件人形成本地消息。首次上传、货站到达/托书跨模块回写、完成计费、自动赶单预警与真实微信均未接通，见 GJ-PRD-119～122、172～176。

货站编号、报价税率候选、已收板纸图片、消息载荷、接收人映射和60 CNY账单均为固定合成样例；费用不是报价计算结果。刷新或恢复重建样例，不把合成关联用作正式匹配规则。

仓库订单从空运模块创建，仓库客服/主管负责编辑和实际服务录入，超级管理员只读查看。已承接全部29项创建字段，另可维护提单号；客户和业务类型必填，可选空值不转零。既有 WMS 货量不能用手工编辑覆盖；待出库订单编辑、已取消订单服务维护、重称覆盖规则保留待确认限制。列表按创建时间倒序、50条分页，选择汇总按委托货量；详情含信息折叠、航班信息、时间正序操作记录、托盘/服务/只读账单。

仓库演示代码 `WH001`、固定日期、账户ID、退件提货地址和已审批费用均为合成配置。接收上游订单须提供独立入仓号；未填写实际量的订单可模拟按新托盘入库，已关联空运仓储服务进入“服务中”，但不改提单货量。收到出库指令进入“待出库”，出库终态受036限制，重称受164限制，不更新库存或自动计费。退货直接读取地面服务的包裹记录，支持父行全选和规定8字段CSV下载，导出客户列按PRD留空；CSV为原型文件格式假设。运输看板读取既有订单、运单和司机事件，双端仓库匹配与缺失ETA不猜测。月报按明确完成时间及业务审批字段统计，金额分币种列示，中转标识与跨月入库未决值不显示为零。航空标签模板未定义，下载入口禁用。

运单页分运输/中转两类，默认演示当天提货、50条分页；中转支持封条号精确查询和异常空白筛选。异常和单据图片选填、最多9张、单张6MB、JPG/PNG/BMP，实际读取和解码，草稿取消不改已存记录；同内容重复图片暂阻断，规则见问题143。普通单据支持新增/修改/删除；杂费类型和金额字段、审批结果/修改后金额/多行备注均已呈现，杂费新增与通过入账受139～140限制，驳回可留痕且不记费。运单应付新增、费用调整和自动计算未覆盖。异常单条且无后续节点时可取消；多异常或期间推进后取消待034确认。待确认订单聚合保留上次状态并显式提示，月报相关完成数不计算。

页首“载入中转合成示例”形成 `GJ-DEMO-TRANSFER-016`、`SEAL-DEMO-016` 已收记录、两条WMS轨迹和一条司机待审批杂费单据；可执行驳回。它不模拟WMS报文匹配成功，不调用外部接口、不自动入账，重复载入不覆盖操作，刷新/恢复后清除。运单账单仅按 `waybillId` 关联，不把订单费用全部复制给每辆车。

用车手工单由“航晟客服”操作，委托方候选来自明确配置的航晟客户档案ID；四个既有客户的关系、有限省市区候选、`DEMO-`账户ID及抄送邮箱均为合成配置，不从名称或部门猜关系。单号原值与系统生成的用车单号分别保留，重复客户单号深链要求选定具体记录，不解决019的正式编号冲突。日期默认演示当天，可选择日期或指定时分；货量原值保留，未知数值范围不参与分配，监管类型因缺少枚举禁用。既有监管值只读保留。陆运月报需切换“航晟陆运主管”，该角色不自动取得建单或调度权限。

在途跟踪包含订单/货物11项、运输/交单11项、航班/服务联系人17项，以及轨迹时间、状态与内容。已绑定值直接投影，缺失值留空，毛件体只读已保存提单数据；卖价、截单日期和未明确绑定的联系人/交单值不推测填充。普通空运客服可查询本人主订单；分单仅展示本人且明确归属该主单的独立服务，不汇总成主单状态。超级管理员可查询全部现有订单及明确关联的分单。查询附加项因含义不明禁用。合成示例 `GJ-DEMO-TRACKING-014` / `781-90001401` 可查看两个运输运单，默认启动已载入；再次载入不覆盖已操作数据，顶部恢复或刷新重置为初始样例。
